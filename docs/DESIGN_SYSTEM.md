# RailHelpAI — Enterprise Design System Specification

> **Version:** v1.0 (UI/UX Transformation Phase)  

---

## 1. Color Palette Tokens

- **Primary Accent (Signal Red):** `#C8102E`
- **Dark Neutral (Charcoal):** `#1E242B`
- **Muted Subtext:** `#5A6672`
- **Background Neutral:** `#F8F9FA`
- **Surface:** `#FFFFFF`
- **Subtle Container Borders:** `#E1E4E8`

---

## 2. Priority & SLA Badges

- **P1 Critical:** `#FEE2E2` bg, `#991B1B` text, `#FCA5A5` border
- **P2 High:** `#FFEDD5` bg, `#C2410C` text, `#FDBA74` border
- **P3 Medium:** `#FEF3C7` bg, `#B45309` text, `#FDE68A` border
- **P4 Low:** `#E0E7FF` bg, `#3730A3` text, `#A5B4FC` border

---

## 3. Typography & Spacing Scale

- **Font Family:** Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Scale:** Display (1.4rem/700), H1 (1.25rem/600), H2 (1.1rem/600), H3 (0.95rem/600), Body (0.85rem/400), Caption (0.75rem/400)
- **Border Radius:** 6px–8px structured card containers.
